Syndi

Syndi is a modern study productivity web application designed to help students organize their learning experience and improve retention.

Features
User Authentication
Flashcards
Quiz Mode
Note Summarization
Task Management
Study Scheduling
Responsive Design
Supabase Integration
Built With
React
Vite
Supabase
JavaScript
CSS
Live Demo

https://syndi-pearl.vercel.app

Installation
npm install
npm run dev
Purpose

This project was built to provide students with a centralized platform for managing study materials, quizzes, schedules, and learning activities.
